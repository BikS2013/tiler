# homebrew-tiler

Homebrew tap for [Tiler](https://github.com/biks2013-tools/tiler): a macOS menu bar tiling window manager that tiles one desktop on one display at a time, only where you turn it on.

## Installation

```bash
brew tap biks2013-tools/tiler
brew install --cask tiler
```

## Upgrade

```bash
brew update
brew upgrade --cask tiler
```

## After installation

1. Open Tiler (menu bar icon, no Dock icon) and allow **Accessibility**: **System Settings** > **Privacy & Security** > **Accessibility** > enable **Tiler**.
2. Click the menu bar icon and choose **Tile This Desktop** (or press **Ctrl+Cmd+P**).
3. Press **Ctrl+Cmd+/** to see every shortcut. Change them in **Settings…**.
4. Press **Ctrl+Cmd+M** to move or resize any untiled window with the arrow keys (⇧ resizes, ⌥ fine steps, C centre, M fill, Return done).

5. Press **Ctrl+Cmd+,** / **Ctrl+Cmd+.** to send the focused window to the previous / next desktop (keep the Mission Control "Move left/right a space" shortcuts on).
6. Optional: menu bar icon → **Focus Follows Mouse**.

Upgrading: open **Settings…** and click **Add Missing Settings** once; it adds the new settings to your config file and changes nothing else.

Decks: [for users and for engineers](https://biks2013-tools.github.io/tiler/).

## Uninstall

```bash
brew uninstall --cask tiler        # removes the app, keeps ~/Library/Application Support/Tiler
brew uninstall --zap --cask tiler  # also removes the configuration and tiled-desktop list
```

## Maintainers

`Casks/tiler.rb` is generated by `scripts/package.sh` in [biks2013-tools/tiler](https://github.com/biks2013-tools/tiler) (copy kept in its `homebrew-tap/` folder). After each release, copy it here and commit it as `tiler <version>`. See that repository's `docs/design/release-runbook.md`.
